# Medtalent 微信原生版

原生工程使用 Page、Component、WXML、WXSS；目录、医生首页、问答、管理、服务和“我的”均在小程序中渲染，无需 WebView。仓库中的 `wechat-miniprogram` 是独立的 WebView 入口工程，部署者按自己的场景选择。

## 先部署自己的后端

按 [独立部署指南](DEPLOYMENT.md) 部署平台，准备可访问的 HTTPS 域名，例如 `https://agents.example.com`。小程序不会自带模型、数据库或微信服务端凭据；AI、语音和微信账户功能须分别配置供应商服务和服务端环境变量。

首次导入前修改：

- `wechat-native/project.config.json`：把 `appid` 改为自己的微信小程序 AppID，并修改项目名称。
- `wechat-native/config.js`：把 `apiOrigin` 改为自己的后端 HTTPS Origin；更新名称、运营主体、隐私邮箱和日期。
- 服务端 `.env.local`：使用相同 AppID，并在启用微信登录时填写自己的 `WECHAT_APP_SECRET`；AppSecret 和模型密钥只保存在服务器。

在自己小程序账号后台配置后端域名为 request 和 downloadFile 合法域名。头像、音频与接口返回的其他下载地址也要核对其域名。原生版无需 WebView 业务域名。隐私指引须覆盖实际启用的录音、账户和健康记录功能；麦克风授权失败时仍可文字问答。

## 导入

在微信开发者工具导入仓库根目录下的 `wechat-native` 文件夹；使用 ZIP 时先解压，再选择其中包含 `project.config.json` 的工程目录。核对已换成自己的 AppID，后端选择“不使用云服务”。已构建的原生工程无需在开发者工具中构建 npm。

修改配置或共享 H5 源码后，按下文重新构建，避免工程与构建清单不一致。发布前保持合法域名校验开启，并用真实微信账号和设备验收。

## 与 H5 共用的内容

- 动态已发布智能体目录、医生资料、内容文章及统一后端 API。
- 示例医生主题、首页与五栏导航，新增智能体使用通用体验。
- 专科记录、睡眠与情绪记录、数据校验、趋势和每日进度。
- 睡眠日记、生理记录、报告、目标打卡、呼吸、冥想音频、自评与卡片。
- 聊天内心情、自评与补充说明；语音识别、发送和播放。
- 收藏、历史、资料、保存设置和健康档案删除；配置微信账户后的同步、冲突选择与主动游客数据迁移。

`utils/models` 和运行层的 CAS、固定提示过滤与语音分句文件由 H5 纯逻辑源码生成。构建清单记录源文件和代码包 SHA-256，源文件变更后必须重新构建。头像由后端管理，品牌插图与 Phosphor 图标为本机打包资源。

页面切换、首页入场、提醒框、消息、浮动按钮与弹层的动效参数从 H5 源码读取；默认弹簧使用项目安装的 Motion 引擎采样生成原生关键帧。系统“减少动态效果”的联动及 iOS/Android 差异需要在自己的设备上验收。

游客数据分别存放于浏览器与小程序各自的本机空间，二者无法互相读取；使用同一微信账户后，共用已保存的云端数据。小程序身份通过原生 `wx.login` 和服务端一次性登录事务获得，微信密钥仅在服务端交换。云端编辑采用相同 CAS、账户隔离与删除语义。

## 构建与检查

需要 Node.js 24.4+。在仓库根目录执行：

```sh
npm ci
npm run build:native
npm run check:native
npm run test:native
npm run package:native
```

PNG 打包所用 `sharp` 已声明为项目构建依赖，随 `npm ci` 安装。无需读取其他工具的内置模块目录。`check:native` 使用微信开发者工具随附的官方 `wcc.exe` / `wcsc.exe`；用 `WECHAT_COMPILER_DIR` 指定实际安装目录中的 `wcc-exec` 文件夹。该编译步骤需要安装相应的微信开发者工具和匹配平台的编译器。

检查会核对页面/组件路由、JS 模块、动态绑定、共享逻辑摘要、代码包文件白名单、主包 2 MB 限制及零 WebView。导入 ZIP 生成在 `output/native/Medtalent-微信原生小程序.zip`。构建、检查和打包只处理本机文件；上传、提审与发布需在自己的微信账号中完成。

量表原文入口使用原生 `wx.downloadFile` / `wx.openDocument` 查看 PDF。使用这些入口时，需核对 `inform-iadr.com`、`www.phqscreeners.com` 等原文链接是否仍有效，以及微信后台是否允许配置这些 downloadFile 域名。下载或查看失败会显示重试提示。

## 验收

本地编译与自动化测试不能替代真机、合法域名或供应商验收。至少验证目录与内容加载、自己的后台登录、微信账户登录和同步、记录增删改、AI 问答及引用、录音授权与播放、PDF 下载与打开、断网重试及 iOS/Android 页面适配。仅为已配置并通过实际验收的功能开放入口。

前端规范与设备检查清单见 [NATIVE_FRONTEND_CONVENTIONS.md](NATIVE_FRONTEND_CONVENTIONS.md)。源码快照不包含既有环境的业务数据或验收输出；为本次部署保存自己的检查结果、代码版本和微信上传版本。
