# 原生小程序前端规范

本规范用于把现有 H5 体验落实到 `wechat-native`，包括新页面、组件和后续修复。以当前 H5 的组件、最终生效样式和真实交互为依据；统一的是来源、实现方法和核对步骤，不是把医生主题全部改成同一种外观。

唐医生的大字号、绿色主题，以及喻雯的紫色主题、心理健康功能卡片，都是 H5 已有变体。保留这些差异，不以“统一规范”为由重新设计。规范中的要求是检查目标，不代表已经在微信开发者工具、iOS 和 Android 全部验收通过。

行号以 2026-10-21 工作区为基准。源码变化后须同时更新引用；核对时以选择器、组件名称和后续覆盖规则定位，不能只依赖旧行号。

## 1. 来源与覆盖顺序

按以下顺序确定页面的最终表现：

1. `src/data/doctorExperience.ts` 的医生主题和公开医生资料。
2. `src/index.css`、`src/pages/doctor-app.css` 的基础样式。
3. `src/features/tang`、`src/features/yuwen`、`src/features/health` 的功能样式，以及页面后部的医生变体、窄屏覆盖。
4. 对应 H5 组件实际渲染的元素、状态和 Motion 参数。
5. 在相同数据、状态和视口下读取 H5 的最终计算样式，并与真实微信截图核对。

不要把未使用的 CSS 当成待移植功能，也不要把原生工程当前存在的偏差反过来写成 H5 规范。生成的 `utils/models`、动效参数和 PNG 图标应修改来源或构建脚本后重新生成，不手改生成结果。

依据：[主题类型](../src/data/doctorExperience.ts#L45)、[基础字体](../src/index.css#L5)、[主题注入](../src/pages/DoctorApp.tsx#L2232)、[原生生成入口](../scripts/build-native-miniprogram.mjs#L35)。

## 3. 字体与字号层级

正文和操作文字使用中文无衬线回退；来源中的衬线标题保留衬线角色。H5 基础为 `Inter, PingFang SC, Microsoft YaHei, system-ui, sans-serif`；标题常用 `STSong, Songti SC, serif`。原生系统没有同名字体时允许系统回退，但须记录设备和字体设置，不承诺不同操作系统字形完全相同。

| 场景 | H5 来源值 | 核对点 |
| --- | --- | --- |
| 医生首页主标题 | 基础 39px、600、衬线；通用医生另有 27px 覆盖 | 应检查窄屏、长姓名和医生变体后的最终值 |
| 管理、服务等页面标题 | 29px、600、衬线 | 不用正文加粗冒充页面标题 |
| 通用弹层标题 | 27px、衬线 | 按当前弹层组件的最终覆盖取字重 |
| 唐医生首页、面板、弹层正文和操作文字 | 16px；正文行高 1.65 | 不回退成通用小字号 |
| 唐医生辅助说明 | 14px、行高 1.65、`#52685d` | 不把说明压成过浅的小字 |
| 唐医生聊天正文 | 16px、行高 1.7 | 长句换行、引用和语音识别内容可读 |
| 喻雯卡片 | 标题 22px；小标题 16px；正文 13px、行高 1.8 | 页面标题和卡片内部标题分开 |
| 喻雯量表 | 内层标题 20px；正文 13px、行高 1.85；提示 12px | 不把所有层级统一改为 29px |

依据：[首页标题](../src/pages/doctor-app.css#L266)、[通用医生覆盖](../src/pages/doctor-app.css#L359)、[页面标题](../src/pages/doctor-app.css#L1905)、[弹层标题](../src/pages/doctor-app.css#L825)、[唐医生变体](../src/pages/doctor-app.css#L3166)、[唐医生聊天](../src/features/tang/tang-voice.css#L1)、[喻雯卡片](../src/features/yuwen/wellness.css#L2)、[量表字级](../src/features/yuwen/wellness-assessments.css#L5)。

不得用全局 `font-weight` 覆盖全部标题或按钮。为每个角色核对最终字号、字重、行高和截断方式；正文、免责声明、错误说明允许换行，不能以省略号隐藏必要信息。

不要给组件内全部 `text` 强加同一个行高。这会覆盖标题、说明和标签各自的行盒，造成页面整体下移。保留 H5 的 `font-synthesis: none`，并检查内联元素所在父行盒；问答页 8px 的内联标签仍位于父元素 16px/24px 的首行，不能简单改成 12px 高的块。

“我的”页账户提示沿用 `ConsumerAccount.tsx` 的完整游客说明，分别检查普通主题的 11px/1.6 与唐医生的 14px/1.65。文字完整性会改变窄屏行数，不能删除句子后用空白补齐。版本页脚按 H5 的上边距 20px、颜色 `#a1aba8`、字距 `.07em`；唐医生另有字级覆盖。版本的平台名称使用准确的“微信原生小程序版”，不标成 H5 或 WebView。该完整名称在 282/337/352px 内容宽度的真实 CSS 文本测量中，保留了普通主题一行、唐医生两行的自然行数；仍须以原生回拍验证实际排版。比较页面高度时同时核对提示行数、账户分隔线、菜单和页脚位置，不能把方向相反的差值抵消后视作通过。

隐私设置的标题块按 H5 的 `b` 元素清零外边距，说明文字保留 4px 上边距。分别检查标题和说明的实际间距及每一行高度；通用标题的 5px 下边距会与说明边距折叠为 5px，在唐医生三行设置中累计多出 3px。规则限定弹层内的设置标题，保留其他标题角色。

普通专科管理页保留 H5 在 380px 的趋势标题网格断点，标题和图标分别占行，间距为 12px。360–380px 的编辑和趋势卡内边距为 14px，更窄的现有 13px 规则继续单独核对。该分支不覆盖唐医生健康管理；390px 的布局不能替代 375px、320px 的实际截图。来源：`doctor-app.css` 的 380px 覆盖及 `specialty-records.css` 的趋势图标间距。

唐医生心情按钮的标签继承按钮的 13px/1.5；引导正文的 1.75 行高不覆盖标签。多行标签须按两行 39px 核对，不能用固定按钮高度掩盖行高差异。符号独立保留 25px/25px 行盒及来源中的 flex gap。

服务页主标题区分普通主题的 1.5 行高与唐医生的 1.65 行高。黄色说明中的标题沿用 H5 的内联排版，并保留父元素生成的行盒；不能把小字号标题改成块后，再用固定高度或额外留白补偿整框差值。该规则只作用于服务页主面板，不覆盖共用弹层标题。

普通首页评估卡标题沿用来源的 24px/1.5。顶部横向标签保留真实滚动容器，普通主题用局部对齐消除行内标签的基线尾隙；唐医生和喻雯单独保留已有分支。核对标题、卡片和顶部区域各自的实际高度，不能让方向相反的局部差异在总高度中互相抵消。

普通主题的标签容器按 H5 实际 27.5px 高度设置，由 9px/1.5 标签文字、上下各 6px 内边距与两条 1px 边框组成。微信滚动容器自动高度可能取整到 28px；长医生资料使顶部区域超过最小高度时，这个误差会传递到后续内容。应匹配该容器本身的高度，不移动后面的卡片。

首页进度标签保留 H5 的内联角色和父级 16px/24px 行盒。将 9px 标签改成块会缩短文字组，并在垂直居中后移动进度数值；即使外卡高度相同也要核对内部坐标。进度数值为 26px/26px、700，不用重复加粗补偿位置差。

专科管理页分别核对合并提示、备注、计数、隐私说明和趋势明细的行高。当前 H5 合并提示为 12px/1.6，备注标签和趋势明细为 12px/1.5，备注计数为 9.6px/1.5，隐私说明为 11px/1.7；明细文字为 `#64756e`。父容器行高正确仍不足以证明子文字正确，须检查子元素是否被通用 `text` 规则覆盖。长列表需要同时比对首行、末行和后续卡片的位置。

输入框内的单位单独核对：普通专科为 10px/1.5、400、`#7d8d87`，唐医生为 12px/1.65、同色。普通单位不能继承字段标签颜色，也不能沿用面板统一的 1.65 行高；修正规则限定普通专科，不改变输入框高度、唐医生或图表与历史记录中的单位文字。

展开控件同时核对图形、文字起点和整行点击范围。普通健康页趋势明细的点击行应与 H5 summary 同宽，至少 44px 高。微信渲染器可能将小数边框取整，三角标记须以实际计算尺寸和原图确认；不要仅凭声明的 3.5px 推定实际宽度，也不要用移动整行来修正图形轮廓。

输入值与占位文字分别核对。例如喻雯日记数值为 16px/400，占位文字为 12px/400；专科备注框继承标签的 700 字重。筛选按钮也按最终值实现，冥想分类当前为 13px，不能套用普通操作的 16px。实际计算值见 `output/native/parity-20261021/h5/computed-wellness-root.json` 和 `h5/cta-probe/computed-ask.json`。

原生 picker 的展示文字与 H5 select 分别核对外框、字段标签和选项文字的位置。相同的 padding 不保证两种控件内部文字落点相同；只有原图确认外框与标签一致后，才对具体展示文字角色作局部对齐，不移动箭头或整个控件，也不从像素偏移推断浏览器匿名内框尺寸。窄屏仍须重新截图验证。

记录列表按日期、来源、测量值、备注分别设置行高和间距，不能靠压缩列表总高度消除逐行累积的偏差。数值和单位保留各自字级；原生 `text` 的规则须检查选择器优先级，避免覆盖这些角色。

## 4. 间距、圆角与按钮状态

复用来源已有数值，不另建强制的 4px/8px 网格来改写现有布局。外层留白、卡片内边距、控件间距分别核对，避免父子容器重复添加内边距。

| 元素 | 来源基线 | 规则 |
| --- | --- | --- |
| 通用主按钮 | 高度至少 49px，左右 16px，间距 8px，圆角 15px | 主题 strong 背景、白字；基础字号 12px/700，医生或功能覆盖另算 |
| 通用次按钮 | 高度至少 46px，顶部间距 8px，圆角 14px，1px 边框 | 白底、次要文字；与主按钮有明确层级 |
| 喻雯操作按钮 | 通常至少 44px，圆角 12px | 量表主次按钮最终为 16px/400、行高 24px；核对实际覆盖后的字级 |
| 喻雯卡片、量表面板 | 内边距 20px，圆角 20px | 记录表单另有 11–12px 控件圆角 |
| 通用底部弹层 | 上圆角 26px，左右内边距 20px，上内边距 22px | 底部计入安全区，内容过长只滚动内容区 |

依据：[主按钮](../src/pages/doctor-app.css#L618)、[次按钮](../src/pages/doctor-app.css#L960)、[喻雯按钮](../src/features/yuwen/wellness.css#L29)、[量表主次按钮](../src/features/yuwen/wellness-assessments.css#L15)、[表单](../src/features/yuwen/wellness.css#L36)、[弹层](../src/pages/doctor-app.css#L792)。

勾选控件分别核对未选、已选和禁用状态的背景、边框与勾形，不能仅凭状态值正确判定外观一致。需要自定义展示时，保留真实 `checkbox` 和 `label` 的点击语义；装饰层不接管点击，外框和文字位置保持来源尺寸，并以真实点击核对状态切换及数据副作用。

### 微信按钮默认主题

本工程由项目 WXSS 接管自定义前端样式，`app.json` 不启用 `style: "v2"` 的默认组件主题。不要为修正按钮宽度临时添加 `size="mini"`：它还会改变 display、padding 等，不能替代项目自己的按钮角色。

微信默认按钮主题可能覆盖项目尺寸。保持 [当前 app.json](../wechat-native/app.json) 的主题设置，并按下述要求在自己的微信开发者工具和真机中核对。

后续修改全局按钮、`style` 配置或组件主题后，必须在真实微信中复核 width、height、padding、display、margin、border 和字级，并留存计算样式及截图；至少覆盖返回、提醒、主次操作、弹层关闭和禁用按钮。宿主浏览器不加载微信内置主题，不能用它证明没有这类覆盖。

按钮必须区分以下状态：

- **普通**：使用对应角色和医生主题；不得在原生默认按钮边框上再叠加业务边框。
- **按下**：按 H5 的 `:active` 转换为原生 `hover-class` 或已有动效。通用主按钮缩放为 0.985；不要把桌面 `:hover` 的悬浮位移当作触屏默认状态。
- **禁用**：保留真实 `disabled` 或事件保护，且不响应按下效果。通用主按钮来源透明度为 0.38 并去掉阴影；量表为 0.45，记录按钮为 0.5；不强制抹平这些组件差异。
- **选中**：使用主题边框、surface 背景、选中图标或状态文字共同表达，不能仅以颜色区分。
- **危险操作**：保留来源的危险色、文案和确认行为，不能做成主按钮样式。

表单错误同时核对字段边框、字段说明和整表提示。使用已有字段错误状态驱动样式，正常提示不继承错误间距；不得只显示错误文案而遗漏来源中的输入框标记。

复制组件规则时同时核对 H5 的基础 reset。记录表单的错误与保存反馈最终外边距为 0，不能从原生通用 `.error` 继承额外留白。定位时比较前一节点、提示节点和按钮的实际坐标，不能仅凭整页高度推断是哪一段间距。

自绘勾选框分别核对未选、已选、禁用未选和禁用已选状态；禁用背景、边框和勾形以实际来源为准，不能直接套用宿主的默认灰色。多行输入的 placeholder 另查字号和行高，不能假定它自动继承输入文字的全部排版。

依据：[主按钮按下与禁用](../src/pages/doctor-app.css#L640)、[量表禁用](../src/features/yuwen/wellness-assessments.css#L4)、[记录按钮](../src/features/yuwen/wellness-records.css#L9)、[选中 chips](../src/features/yuwen/wellness.css#L32)。已有 28px/36px 的提示关闭或图标操作是具体组件变体，不通过全局规则随意放大；新增同类控件沿用对应来源并实测触控。

## 5. 图标、头像与资源

使用 H5 同名图标及其实际权重和颜色：主体为 Phosphor 的 `regular / duotone / fill`，唐医生引导中的 Heart、ClipboardList 使用来源的 Lucide 描边。导航和收藏的选中态要切换对应 fill 资源，不能只染色；不得以 emoji、Unicode 字符或相近图标替代已有资源。图标尺寸按角色核对，区分图形大小和按钮触控区域。

原生 PNG 由构建脚本生成，调用 `presentation.icon(name, tone)`；新增别名应在别名表和生成列表中登记。PNG 的生成尺寸不等于显示尺寸，不通过拉伸或裁剪改变线条粗细。医生头像继续使用公开资料中的位置、缩放、Y 偏移和变换原点，不能统一改为一个居中裁切。

同名图标按用途区分尺寸与前景色，例如量表入口、历史入口和列表箭头不能共用一个默认尺寸。对粗细或图形有疑问时先核对 H5 实际组件、默认权重及生成 SVG，再检查原图；不得仅凭缩略图将笔形图标误改成加号。

心情中的云和太阳沿用 H5 的原始 Unicode 文字符号，生成原生图片时须先确认实际 fallback 字体，不能仅看 CSS 的 `Georgia, serif` 声明。2026-10-22 的真实 CDP 结果为 Noto Serif SC、400 字重；25px 行盒的实际文字基线为 21px。`native-guidance-mood-glyphs.mjs` 使用该实例的原始字体单位轮廓，以 `translate(0 21) scale(0.025 -0.025)` 转换，再生成 75px 图片；不按包围盒缩放，不用近似图标替代。其余三个符号保留来源文本分支。旧截图若处于不同字体环境，保留原标记并重拍受影响场景，不能用源代码未变化代替实际字体一致的证据。

目录的 ShieldCheck 按三个实际用途生成独立资源：顶部徽标为 15px、regular、`#4386be`；主说明为 16px、duotone、`#3d77b6`；页脚为 18px、duotone、`#3d77b6`。这类少量页面专用角色只生成所需资源，不扩展整个色板下的全部图标；原生显示尺寸和三倍 PNG 尺寸分别登记。

首页记录按钮下的隐私 ShieldCheck 为 15px、duotone，普通主题颜色为 `#99a5a1`，唐医生为 `#52685d`。图片不会自动继承父级文字颜色，应使用对应角色的三倍资源；不全局替换其他用途的 muted 图标。

## 6. 弹层、滚动与键盘

服务和已发布内容的弹层按实际内容高度保留小数，配合 CSS 视口上限处理长内容。不要先把自然高度向上取整；这会移动整个短弹层。Education 显式使用小数高度策略，Home 记录弹层沿用已有策略。页脚盾牌为 14px，上边距为 1px；同时核对图标、文字和所在 flex 行的高度，避免图标外边距抬高整行。

专科趋势图按 `SpecialtyManagePanel.tsx` 的 320×165 SVG 坐标等比呈现，保留缺失日期断线、实际纵轴、状态标签及主题线条/圆点的区别。原生画布可将当前真实绘图导出为按设备像素比生成的 PNG，再由同尺寸 image 显示；不得使用固定数据截图。导出和图片加载须绑定当前医生、账户、图表内容及生命周期，过期回调不能替换新图。冷启动、首次滚入、切换指标、切换日期范围和无数据状态须分别留存真实微信截图，画布 backing 有像素不能单独证明屏幕已经显示。

横向滚动图表的内留白放在实际内容包装层，核对 `scrollWidth`、末端可达位置、最后一个日期和选中边框是否完整；同时复查不溢出的周视图，避免仅修复月视图后改变周图宽度。

- 弹层保持底部进入、遮罩、关闭按钮和内容滚动。退出动画结束前保留内容；重新打开、换账户、换页签、隐藏或卸载后，旧关闭回调不得关闭新内容。
- 弹层的 H5 高度基准是去掉原生顶部栏和底部安全区后的内容舞台，不扣除舞台内的应用导航。H5 的 88% 上限换算为该舞台的 88%，原生容器另保留一次底部安全区；共用 FeatureSheet 的正文上限还受 720px 约束。
- 滚动正文保留实际自然高度，由 CSS 随可用视口限制最大高度。窗口宽度变化时重测换行；缩小再放大、键盘收起后同步恢复弹层限制。旧医生、旧内容、关闭中、隐藏和卸载后的测量结果不得覆盖当前弹层。
- 唐医生首页记录弹层的关闭按钮位于滚动正文内，沿用 H5 的 sticky 位置及负外边距，不能以外层绝对定位代替；按实际截图核对初始位置和滚动后的吸顶位置。
- 每个主内容区域只设一个纵向滚动容器。聊天的消息、错误详情和底部内容放在同一消息滚动区域；不要叠加页面整体滚动和聊天滚动。
- 长回复默认跟随底部；上翻历史或展开识别内容、引用后暂停跟随。程序产生的 scroll 事件和正文变高不能冒充用户手势；明确发送新问题后恢复跟随。
- 主动点“错误详情”是独立定位：把详情带入视野，仍保持自动跟随暂停。关闭详情不得删除回复或重置历史位置。
- 键盘高度与窗口缩小只计算一次。分别验证覆盖式键盘、宿主先 resize、键盘先回调、关闭、横竖屏和切后台；不能同时由宿主和自定义容器重复缩小或上推。
- 原生状态栏、胶囊、安全区由实际宿主尺寸计算。键盘关闭后恢复导航和底部空间，不保留空洞。未填写的健康记录不因布局切换而清空。

## 7. 动效与减少动态效果

动效从实际渲染的 H5 组件读取。页面切换、消息入场、弹层、提醒框、按钮按下分开记录；不能把所有动效替换为同一个时长或 easing。弹簧由当前安装的 Motion 版本和来源参数派生，记录采样方式与构建摘要。

H5 减少动态效果规则覆盖 `.journey-stage` 全部后代及伪元素：滚动改为 `auto`，动画时长 0.01ms、次数 1，过渡时长 0.01ms。原生必须检查按钮、view、text、image、scroll-view 及实际伪元素的动画和过渡，并检查 JS 控制的平滑滚动、原生动画队列和卸载计时器；不能只缩短按钮过渡就称完成联动。

原生当前在 `app.wxss` 同时提供 `.is-reduced-motion` 和媒体查询规则，医生页的 `scroll-with-animation` 还必须受 `!reduceMotion` 约束。CSS、WXML 绑定和 JS 动画应一并核对；这些分支存在不代表系统偏好已能自动传入。

首页提醒框先提交挂载及当前姿态，再用 `Component.animate` 播放来源弹簧采样；完成后写入稳定样式并清理动画。快速反向要沿用当前采样位置和速度，隐藏、医生切换及卸载时取消旧回调。实际截图必须确认内容可见和最终透明度为 1；仅 `noticeOpen=true` 不能证明提示已经显示。

系统“减少动态效果”的微信读值接口和 WXSS 媒体查询响应仍未确认。`checkIsOpenAccessibility` 的旁白/TalkBack 状态不是该偏好；默认 `false` 也不能记为已读取系统设置。允许在测试中显式注入 reduce 状态验证分支，但证据须注明注入，iOS/Android 的实际系统联动单独验收。

`wx.createAnimation().step().export()` 可以描述原生步链；`export()` 清空实例已描述操作，不等于已有“立即中断组件当前队列”的保证。快速反向、连续开合、后台恢复和桥接延迟需在真实微信检查，不能用宿主浏览器结果替代。

依据：[H5 页面切换](../src/pages/DoctorApp.tsx#L2248)、[消息入场](../src/pages/DoctorApp.tsx#L1519)、[弹层弹簧](../src/pages/DoctorApp.tsx#L1646)、[H5 减少动态效果](../src/pages/doctor-app.css#L3154)、[生成动效](../scripts/build-native-miniprogram.mjs#L51)。

## 9. 组件共享样式与无障碍

原生业务组件保持 `styleIsolation: "apply-shared"`。现有 home、education、health、wellness、guidance、questionnaire 均以其组件 JSON 为准。全局只放确需共享的 reset、主题角色和通用状态；组件特有规则使用组件前缀，避免全局 `button`、`text` 选择器覆盖其他组件。

绝对定位的弹层拖柄要显式清除继承的静态负外边距，初始按弹层上缘内 12px 定位；仍在正常文档流中的拖柄沿用原有 padding 和 margin。拖柄与上、下内边距应进入同一滚动内容，安全区留在滚动区外，不能让固定留白遮住滚动正文。滚动视口须给焦点描边留出绘制空间，同时保持正文宽度、文字起点和 sticky 关闭按钮的位置；关闭按钮的锁定位置按 H5 实际滚动后的坐标核对。带固定尺寸、边框和内边距的 `text` 角标或错误提示显式使用 `box-sizing: border-box`；不能假设原生 `text` 已进入全局盒模型重置。

字号相同时仍要核对最终行高及 inline/block 行框。服务弹层标题按 H5 实测使用 27px，普通主题行高 1.5、唐劲松主题 1.65；提醒标题保持来源的行内排版。专科空趋势和空历史标题显式使用 12px、行高 1.6、颜色 #52665f、无额外底外边距，避免继承通用空状态的 15px。记录日期的数据值始终保留 ISO 格式，显示层使用与 H5 对齐的斜杠日期和日历标记，点击仍进入原生日期选择器。

统计卡片遵循 H5 的实际渲染条件；数组为空时不保留带外边距的空网格。覆盖规则须核对选择器优先级，包含 `text` 标签的旧规则可能优先于后置的单类规则。差值须能对应具体节点，不能靠调整整页 padding 或固定高度补齐。

检查最终可见文字的嵌套节点：外层 label 的 400 字重不能代表内层 strong 的 700。按钮同时核对来源的全局 reset 和组件覆盖规则；局部文件没有字号声明，也可能通过 `font: inherit` 使用正文 16px。

喻雯记录字段使用主题正文色；备注标签与输入文字分别明确字重，避免输入框继承标签的 600。备注文字为 13px、行高 1.8，三行加内边距与边框对应 96.2px；计数文字与框底的实际间距为 10px，包含 H5 行内控件的基线留白。不能只照抄 `margin-top:4px` 而忽略该留白。备注提示色为 `#aaa1b3`；记录页眉小字行高为 1.5，公共页脚为 1.85，均须核对后部覆盖规则。

原生单行 `input` 另查控件内部文字的最终字体与垂直位置。父级已经设置主题字体，不代表输入值会自动继承；目标编辑框显式使用 `font-family:inherit`。固定高度为 46.5px 的单行输入框使用 `padding:0 12px`，保留字号 15px、行高 1.5，并用实际有值原图核对居中。不能直接搬用 H5 的纵向 padding，否则原生控件内部行框可能再次加入留白。图标与文字之间同时检查 flex gap、图标 margin 和 JSX 空白，避免重复计算间距。

唐医生资源说明使用 16px、行高 1.5，对应 H5 的 24px 行框；不继承其他说明文字的 1.65。语音状态中的重试按钮显式使用 flex 居中，标题图标后的来源空格以 WXML 字符串插值保留。展开标记的字形尺寸与占位宽度分别处理，新增宽度仅限定于语音错误和识别内容两个父级；共享样式下不能用通用标记类覆盖练习组件。

语音历史的识别内容入口保留 28px 点击高度，内部文字按基线对齐；其 23.8px 行框不再在按钮内额外居中。H5 的原生 summary 与微信装饰字形可能有栅格差异，文字起点、行框与点击范围须分别核对，不能为字形边缘差异平移整行或改变滚动高度。

禁用态核对实际 `opacity`、文字色和背景色，不能只检查源码声明。微信默认禁用样式会覆盖情绪按钮的颜色，因此在情绪按钮内明确保留 H5 的透明度 0.48、文字色 #73533e 和背景色 #fffcf8；已选项保留 #f3e5d8。布局诊断若尚未执行截图阶段的滚动条隐藏规则，其绝对宽度和高度仅作上下文，不直接认定为双端页面差异。

评估卡片的小字另核对 H5 父级匿名行框，不能只按小字自身行高推算卡片高度。历史列表保留独立列表容器，让顶部留白、末行边框和“展开更多”按钮分别对应来源；行内按钮产生的基线留白计入实际流高。展开三角使用装饰节点绘制，并保持原按钮、点击绑定和展开语义；来源链接的下划线设置到实际承载文字的节点。

记录表单的分组入口按 H5 的 `clamp(section.offsetTop - 24, 0, maxScrollTop)` 定位。原生 `scroll-into-view` 的目标设在分组上方 24px 的不可见锚点，锚点脱离文档流且不接收交互，不改变表单高度；不能用 `display:none` 隐藏定位目标。每次调整滚动容器后，分别核对睡眠、情绪和已被底部钳制的日常功能入口，保留首次定位与完整滚动两类原始截图。

新增共享类后至少检查全部六类组件，确认全局规则实际进入组件并且没有字号、按钮、图标或弹层泄漏。不要依赖浏览器宿主的标签映射证明微信样式隔离行为。

危险色与整块危险按钮分开定义。全局 `.journey-danger-button` 可定义整块按钮，组件内的 `.danger` 只表达当前动作的危险角色，不应被全局强加 `width:100%`、背景和内边距。个人中心的清空按钮由 `.sheet .danger` 明确接管；健康记录、练习历史中的行内删除沿用各自来源样式。

只有图标的按钮必须有具体 `aria-label`，例如“朗读回复”“删除某日记录”“关闭输入提示”。装饰图形不重复朗读；展开和选中控件同步表达状态。输入框保留可识别名称、单位、范围及错误提示，不只依赖 placeholder。加载/错误使用合适的 status/alert 语义；录音计时不每秒重复打断读屏。H5 的可见焦点样式要保留，微信读屏顺序和原生控件仍需实测。

## 10. 每次迭代的核对步骤

1. 先列出受影响医生、页签、组件和状态；保存对应 H5 来源、最终样式值和对照截图，不从原生偏差生成新基准。
2. 修改来源或原生适配层，重建共享模型、图标和动效；保留实际数据边界，不使用生产用户记录作测试样本。
3. 运行 `npm run build:native`、`npm run check:native`、相关专项测试；改到共享布局或状态流时执行 `npm run test:native`，涉及共享 H5 源码时再执行 H5 构建与回归。
4. 按页截图：目录、全部 11 位医生的首页/问答/管理/服务/我的，以及各自账户、隐私和其他弹层；喻雯另含量表/日记/报告/目标/练习，唐医生另含心理引导和逐题量表。每项包含空、已填、长内容、加载或失败中实际适用的状态，逐项关联同状态 H5 基准与实际微信截图。
5. 在 320px、375px 逻辑宽度核对外留白、标题换行、图标比例、按钮高宽、底部空间和横向溢出。聊天另查键盘、录音/识别/生成/播报、打字发送、历史暂停及错误详情；弹层查进入、退出和快速反向。
6. 用同一医生、数据、状态和视口比较 H5 与实际微信。宿主模拟只用于补充定位；实际微信截图先检查缩放和像素尺寸，不把低分辨率截图放大后当作原始清晰截图。
7. 对每个差异记录来源、截图 ID、期望/实际、严重程度及处理结果。调整全局规则后重新核对受影响组件和页面，不能只复看修改处。
8. 最后打包，核对当前源码构建清单、ZIP SHA-256 和文件数。源码或资源再次变化后，旧截图和旧 ZIP 不自动代表新候选。

几何诊断保留浮点坐标、computed height 和原始滚动值。SDK 的 `size()` 可能返回整数，不能把其四舍五入差异当作需要补偿的 1px 布局问题。

这些命令和截图是本地验证工作。上传、提审、发布和生产数据操作继续使用既有明确授权边界；本规范不增加发布权限，也不把本地通过写成全端验收。

## 11. 截图 manifest

每轮使用机器可读 manifest，三个来源分开记录：

- `h5`：真实 H5 页面，记录浏览器和 URL；用于设计与行为基准。
- `actual-wechat`：真实微信开发者工具或微信客户端渲染；必须再用 `platform` 区分 `devtools / ios / android`，开发者工具截图不等于手机验收。
- `host-render`：浏览器导出的模拟宿主，标明原语替代和权限/键盘/控件局限；不得改名成微信截图。

以下字段是模板要求，不是某次已通过的结果：

| 字段 | 要求 |
| --- | --- |
| `schemaVersion`、`runId`、`capturedAt` | 版本、唯一轮次、UTC 时间 |
| `candidate.sourceManifestSha256`、`packageSha256` | 绑定源码清单和实际 ZIP；未打包时 ZIP 为 null |
| `id`、`source`、`platform`、`rendererVersion` | 唯一截图 ID、三个来源之一、实际平台、可验证的版本；未知为 null |
| `doctorSlug`、`tab`、`view`、`state` | 说明哪个页面及状态，不能只写“首页正常” |
| `fixture`、`apiEnvironment`、`accountScope` | 测试数据来源/摘要、本地或其他 API 环境、游客或匿名测试账户；不记录凭据及真实隐私数据 |
| `viewport.width/height`、`image.width/height`、`devicePixelRatio` | 分开记录逻辑视口和 PNG 像素；不能从 PNG 反推视口后冒充已测量 |
| `simulatorZoom`、`captureScale`、`crop` | 明确开发者工具缩放、采集缩放和裁切；未知为 null，不默认为 100% |
| `keyboard`、`safeArea`、`motionPreference` | 记录实际场景；系统偏好未读到为 `unknown`，测试注入另记 `motionOverride` |
| `imagePath`、`sha256`、`baselineId` | 原始图像位置、图像摘要、对应 H5 基准 ID |
| `checks`、`differences`、`limitations` | 单项结果为 `pass / fail / pending / not-applicable`，差异和局限独立列出 |
| `reviewedAt`、`reviewer`、`visualAccepted` | 未检查时为 null；只有实际复核的场景可写 true，不由测试通过或编译通过自动赋值 |

操作系统字体、权限界面、系统减少动态效果、真实录音/播放、后台生命周期和同账号跨设备同步，应各有实际平台证据或明确 `pending`。任何截图来源都不能替代未执行的供应商、身份、域名配置或发布验收。

## 12. 真机验收补充

以下保留导入包的完整真机检查范围；列出检查项不代表已经完成。

手机验收需要 iOS/Android 微信分别核对：目录与各医生五栏；320/375px 布局、长内容滚动和弹层；键盘弹起/关闭；录音允许/拒绝/撤销、切后台、录音识别取消；语音播报中打字/发送/关闭；同账号两设备登录同步、冲突选择、注销；关闭保存后对话及自评清除；音频真实播放与后台暂停；新发布智能体与上下线内容；断网恢复和公开分享入口。

微信系统胶囊、状态栏、安全区和键盘由宿主控制，字体可能随系统变化。页面主题与交互按当前 H5 对齐，最终逐项视觉一致性需以微信模拟器和手机对照截图确认。
