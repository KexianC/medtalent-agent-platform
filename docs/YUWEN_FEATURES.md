# 喻雯身心空间

本次依据用户确认的 YW 功能清单，实现第 1–7、9、10 项。第 8 项定时提醒与异常预警不在本次范围内。落点为独立 `agent-platform` 的 `/d/yu-wen`，沿用紫色主题和原有五栏导航。

## 功能

| 项目 | 行为与入口 |
| --- | --- |
| 睡眠与情绪日记 | 首页“写下今日感受”，支持睡眠、情绪、触发事件、应对方式与文字日记；可补录、修改、删除。睡眠质量、心情、精力、压力均使用明确标注的 0–10 分记录刻度。 |
| 呼吸放松 | 4 秒吸气、6 秒呼气；可选 4–4–6 节奏，支持 1/3/5 分钟、暂停继续和结束，保存实际时长。 |
| 冥想课程 | 三段原创合成语音课程：回到当下、身体放松、睡前安静。真实 AAC 音频、暂停/继续、进度条、逐字稿与聆听记录；不冒充医生本人录音。 |
| 心理自评 | GAD-7 与 PHQ-2，完整问答、缺答拦截、结果说明、同量表历史比较和删除；具体来源、计分及许可见 `YUWEN_ASSESSMENT_SOURCES.md`。 |
| 目标打卡 | 自设日记、冥想、运动、步数、睡眠或自定义目标；依据记录显示进度，由用户主动确认打卡，可编辑、撤销和删除。 |
| 趋势报告 | 近 7/30 日指标均值、逐日图表和明细，缺失项不算零；生活指标与心情关联只使用同日有效数据，并说明不代表因果。 |
| 生理健康记录 | 手动填写步数、心率、血压、体重、饮食摄入热量、运动时长及腰臀围；与日记按同一天合并，保存一类表单会保留另一类的数据。 |
| MBTI 趣味探索 | 20 道原创偏好题、4 个维度、16 种完整结果介绍及历史；明确为趣味探索，不是官方 MBTI 测评。 |
| 趣味占卜卡 | 8 张随机象征卡，提供日常反思提示与历史记录；不作未来预测或医疗解释。 |

## 数据与兼容

- 所有新增个人数据保存在现有“医生 + 游客”隔离的本机空间，刷新后保留；不自动向问答接口发送，不声称跨设备同步。
- 新版记录按日期去重，支持清除单项与整日删除。旧版健康记录仍可在“我的”查看；已有问答、收藏和其他医生页面保持原实现。
- 日期按本机自然日处理；目标跨午夜及页面重新激活时更新。缺失、损坏、超出输入范围的数据独立过滤，不生成虚构分数。
- 呼吸切后台自动暂停，离开页面保存实际练习；冥想离开页面会停止并记录已听时长，拖动进度不作为聆听时长。
- 音频为本地合成引导，不依赖付费 TTS、远端课程列表或新增生产接口。
