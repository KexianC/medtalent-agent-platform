# Medtalent 智能体 · 微信小程序入口

这是可直接导入微信开发者工具的**原生小程序工程**，无需安装 npm 依赖、无需构建 H5。进入首页后点击“进入智能体应用”，通过 WebView 打开正式平台 `https://agent.hzmwmt.com/`，包含动态智能体目录及各智能体的现有功能。

当前工程已填写用户提供的正式配置：AppID `wx7a4c71565eeee4b9`；运营主体“木吾木同(杭州)医疗管理有限公司”；隐私与联系邮箱 `medtalent@medtalent.com.cn`。代码、配置与公开 HTTPS 服务检查通过后，仍须在对应微信账号完成业务域名、隐私指引、资质及真机验收，再上传提审。生成压缩包不代表微信审核通过。

## 1. 导入与填写

1. 解压 ZIP 到一个普通目录，或直接使用仓库的 `wechat-miniprogram` 目录。
2. 微信开发者工具 → 小程序 → 导入项目，选择**包含本文件与 project.config.json 的目录**。不要选择外层 `agent-platform`，也不要选择历史 `dist-wx`。
3. 导入时核对 AppID 为 `wx7a4c71565eeee4b9`，并使用具有该小程序开发权限的微信账号。真实 AppID 已写入 `project.config.json`，无需重复填写，也不要改回游客模式。
4. 后端服务选择“不使用云服务”。本工程调用已有 HTTPS H5 服务，无须开通云开发、运行“构建 npm”或填写 AppSecret。
5. `config.js` 已填入 `operatorName`（木吾木同(杭州)医疗管理有限公司）、`privacyEmail`（medtalent@medtalent.com.cn）。核对这些信息与账号/实际运营一致，并核对 `appName`、`version`、`privacyUpdatedAt`；使用不同正式域名时才修改 `h5Origin`。
6. 保持项目“校验合法域名、web-view 业务域名、TLS 版本以及 HTTPS 证书”开启。不要用关闭校验的模拟器结果作为上线依据。`project.private.config.json` 可能覆盖公共配置，也需要核对。

小程序不读取服务器 `.env.local`，没有登录/鉴权密钥；只有上面这几个公开配置。`config.js` 应保持纯字符串对象，便于发布检查。

## 2. 配置 WebView 业务域名

在对应小程序的微信公众平台 → 开发管理 → 开发设置 → **业务域名**，添加 `agent.hzmwmt.com`（不带路径）。微信会要求管理员扫码并下载校验文件；将原文件部署到该 HTTPS 域名根路径，使微信指定的地址返回原始文本与 HTTP 200，不能返回网站首页 HTML、登录页或跳转页，然后保存验证。

2026-09-07 已将你提供的 `A8m4UZV2fV.txt` 部署到边缘网站根目录，并为 HTTP、HTTPS 增加该文件的精确静态路径。校验地址为 `https://agent.hzmwmt.com/A8m4UZV2fV.txt`，原文件内容保持不变。现在可返回微信后台重新执行业务域名校验；网站文件可下载不代表微信后台已经保存绑定成功。

校验文件与小程序账号绑定；放在本地小程序目录不能完成网站域名校验。若微信以后生成其他文件名，需重新部署相应文件及精确路径。无需为本次服务器校验文件重新上传小程序代码。

账号必须具备 WebView/业务域名权限；个人主体通常不具备。请以账号后台显示为准。腾讯官方产品文档说明了业务域名、企业账号与校验文件流程：[域名配置指南](https://cloud.tencent.com/document/product/1301/100434)。

微信登录使用原生 `wx.request`，请同时将 `https://agent.hzmwmt.com` 添加到 **request 合法域名**。H5 页面仍需要 WebView 业务域名；两种配置不能替代。此工程不使用 `wx.uploadFile` 或 `wx.connectSocket`。

## 3. 隐私、资料与服务类目

- 本地“隐私说明”描述问答、语音、健康记录、微信账号登录、数据库同步、本机存储和服务器日志。它是应用说明，不能替代微信后台的《小程序用户隐私保护指引》。
- 运营方需核对实际模型/语音服务提供方、数据处理地点和保留期限，补充必要的处理说明，确保与线上行为及主体信息一致；不能把本应用描述为“完全不处理任何用户信息”。如修改说明，相应更新日期。
- 原生入口不请求手机号、位置、录音、剪贴板、通讯录等权限；H5 语音仍受微信 WebView、系统麦克风权限和当前 H5 实现约束。拒绝麦克风权限应可以继续文字问答。
- 按实际业务选择微信服务类目，完成账号认证、备案、健康内容/医生资料授权及平台要求的资质材料。不要将不具备的诊疗、处方、在线医生接诊能力写进简介。
- 上线内容不能只为审核临时隐藏或替换。入口所指向的线上 H5 及后续内容也属于实际服务。

微信后台隐私配置与版本审核流程可参考：[腾讯官方隐私适配说明](https://cloud.tencent.com/document/product/1301/97930)。账号后台的当前要求优先。

## 4. 真机预览与上传

1. 开发者工具点“编译”，先看原生首页，再点“进入智能体应用”。
2. 手机微信扫码“预览”，逐项完成下方验收；开发者工具能打开 H5 不代表手机已通过业务域名校验。
3. 在项目详情核对真实 AppID、基础库版本、域名校验及代码包。工程固定基础库 `3.8.10`，如工具提示需下载/不支持，选择账号可用的稳定基础库并重新预览。
4. 点开发者工具“上传”，本版版本号为 `1.0.3`，版本描述可使用下方模板。
5. 登录同一 AppID 的微信公众平台 → 管理/版本管理 → 开发版本 → **提交审核**，填写类目、功能页面、隐私声明及所需资质。开发者工具上传完成并不等于提交审核。
6. 审核通过后，运营方再在公众平台执行发布。

真机验收清单：

- [ ] 首页、隐私说明、使用须知、关于页面完整可读，主体与邮箱真实有效。
- [ ] 在 iOS 和 Android 微信中打开线上智能体目录，进入一个智能体，切换问答、科普、记录和“我的”。
- [ ] 发送非敏感测试问题，收到真实回答；接口故障有提示。不要用真实患者资料做测试。
- [ ] 如果保留语音功能，分别测试麦克风拒绝/允许、开始/结束/取消、转写、发送与播放；当前设备不支持时确认文字功能可继续使用。尚未通过真机验证的能力不能宣称可用。
- [ ] 查看、删除本机记录；核对是否分享健康记录的选择与提示。
- [ ] 点击“微信一键登录”，自动返回后确认账号状态；两台手机使用同一微信账号验证已同步的聊天、健康记录和问卷，不同账号不能读取彼此数据。
- [ ] 登录过程中取消、断网、超时可恢复；退出账号后不显示其私有数据；微信后台已添加 request 合法域名。
- [ ] 从智能体页转发给测试账号：卡片使用固定品牌图，打开同一智能体，链接和图片没有聊天/健康记录。
- [ ] 断网时已打开网页不被自动销毁；首次加载失败时有重试；恢复网络后能重新加载；返回入口与重新进入正常。
- [ ] 不需要后台管理员账号就能浏览与测试用户功能；审核说明不要提供运营后台密码。

## 5. 可复制的审核材料

**功能简介**

提供健康知识浏览、人工智能科普问答与个人健康记录工具。用户可以在统一目录中选择智能体，阅读科普内容、提出健康知识问题并管理记录；微信登录后可在其他设备查看已同步的数据。人工智能内容仅供参考，不提供诊断、处方或替代医生诊疗。

**版本描述**

修复微信登录返回时重建网页的问题，保留原页面与输入内容；防止重复返回退出核心功能页面。直接打开无参数登录页时先进入公开应用，再从“我的”发起登录。配合网页端登录状态与记录加载修复，保留游客浏览、科普问答和账号同步功能。

**审核路径**

`pages/index/index` → 进入智能体应用 → 选择一个已发布智能体 → 问答/科普/记录/我的。原生首页底部可进入隐私说明、使用须知及关于与帮助。用户端无需后台管理员登录。业务网页为 `https://agent.hzmwmt.com/`，核心内容与接口由正式平台提供。

**示例测试问题**：日常作息有哪些一般性的健康建议？

## 6. 路由与维护

H5 → 原生能力页已实现微信登录，是否可用同时由服务端配置决定；手机号授权、支付和订阅消息继续关闭。详细的接口约定与流程见 [微信能力接入说明](docs/WECHAT_BRIDGE.md)。H5 SDK 和后端实现位于外层 `agent-platform` 源码，不包含于小程序代码上传包；三端版本需配套发布。仅更新 H5 无法让旧版小程序获得原生登录能力。

| 页面 | 用途 |
| --- | --- |
| `pages/index/index` | 原生统一入口、使用边界及说明入口 |
| `pages/webview/index` | 正式 H5、加载状态、错误恢复、分享 |
| `pages/about/index` | 联系方式、帮助、微信隐私指引 |
| `pages/policy/index?type=privacy` | 隐私说明 |
| `pages/policy/index?type=terms` | 使用须知 |
| `pages/capability/index` | 微信登录、失败重试与取消；手机号、支付、订阅消息仍关闭 |

支持以下公开智能体入口（以唐劲松为例）：

| 用途 | 网页地址 | 小程序页面路径 |
| --- | --- | --- |
| 智能体首页 | `https://agent.hzmwmt.com/d/tang-jinsong` | `pages/webview/index?path=%2Fd%2Ftang-jinsong` |
| 直接进入问答 | `https://agent.hzmwmt.com/d/tang-jinsong/ask` | `pages/webview/index?path=%2Fd%2Ftang-jinsong%2Fask` |

只接受 `/`、`/d/{slug}` 与 `/d/{slug}/ask`，末尾斜杠会移除，不接收其他子路径、外站 URL、管理后台地址、聊天或健康信息。分享保留公开首页或问答入口，查询参数和 hash 会丢弃，不携带对话内容或本机记录；不用 `postMessage` 模拟实时通信。

问答直达同时依赖 H5 的 `/ask` 页面路由及此版小程序路径白名单。旧版小程序只接受智能体首页，传入 `/ask` 会回到广场；需上传、审核并发布包含此改动的新版小程序后，再在公众号使用问答直达的小程序页面路径。仅发布 H5 不会更新已发布的小程序路径白名单。

H5 后续发布的智能体自动出现在统一目录中，无需重新生成入口。小程序源码、权限、隐私说明或入口域名变化仍需按微信流程重新上传审核；H5 变更也应保持与已申报服务相符。

在外层 `agent-platform` 目录可执行：

```powershell
npm run check:wechat
npm run test:wechat
npm run check:wechat:release
npm run package:wechat
```

`check:wechat` 是本地结构检查，缺失 AppID/主体/邮箱会列为待填；`check:wechat:release` 严格阻止这些缺失项并验证公开 HTTPS 服务。它不连接微信账号，无法验证备案、业务域名绑定、资质或审核结果。ZIP 输出至 `output/wechat/Medtalent-微信小程序.zip`，仅包含小程序文件，不含服务器、密钥、数据或后台源码。

官方 API 参考：[web-view](https://developers.weixin.qq.com/miniprogram/dev/component/web-view.html)、[项目配置](https://developers.weixin.qq.com/miniprogram/dev/devtools/projectconfig.html)、[发布流程](https://developers.weixin.qq.com/miniprogram/dev/framework/quickstart/release.html)。本次这些微信文档页面未能直接读取；上述操作需结合当前公众平台界面核对。
